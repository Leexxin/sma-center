# 统一控制台方案与实现

2026-11-06。本页保留首轮统一方案；后续资源独立页面及卡片管理/插件调整以[卡片插件规范](card-plugins.md)为准。以总览为唯一工作入口，资源是卡片的数据来源；管理动作在当前面板内完成。业务应用已并入资源页（见[面板说明](workspace.md)），旧 `/applications` 跳转至资源页；版本中心、服务器详情、安全设置继续使用独立 URL，但共用导航与视觉规范。

## 界面取舍

| Before | After | Why |
| --- | --- | --- |
| 总览与独立资源面板各有导航、设置和主题 | 总览承担卡片与资源管理，旧 `/resources` 跳转到 `/?view=resources` | 不再来回切换两套面板 |
| 新建、编辑资源需要离开面板 | 侧栏“资源”打开列表，搜索、分类、新增、编辑、收藏和删除在弹窗中完成 | 保留当前工作位置 |
| 卡片配置不能直接创建数据源 | 配置卡片时可新建资源，保存后自动绑定；资源列表可直接加入当前面板草稿 | 缩短配置路径，布局仍须显式保存 |
| 版本中心、服务发现和原生认证页采用不同外观 | 使用同一侧栏、总览返回入口、字体、间距、表面和分隔线 | 页面切换保持一致 |
| 页面设置包含旧主页名称、欢迎语等字段 | 统一“设置”只提供明暗、强调色、密度和 JSON 备份 | 控件只保留当前有效功能，旧字段原样保留在存储中 |
| 主机详细指标分散在旧资源卡中 | 总览资源详情与服务器页共用主机指标组件 | 保留文件系统、磁盘速率、采集错误及不支持指标的解释 |

## 统一规范

系统字体，浅色与深色中性表面，单一强调色、轻分隔线、统一按钮和表单；沿用已选定的蓝色 S 图标。桌面侧栏固定，手机收进右上角导航。内容随宽度折行，长地址和代码块在自身容器滚动。提供键盘焦点、图标按钮名称和减少动态效果支持；不使用常驻欢迎口号或重复身份说明。

React 页面通过 `ConsoleShell` 共用框架；原生 TOTP、应用目录、OIDC 同意页面通过 `nativePage` 输出相同框架。设计变量及公共样式统一维护在 `public/console.css`，由 React 全局样式导入，原生页直接加载同源 CSS。版本中心和服务发现只保留内容布局样式。原生页仍为无脚本表单，CSP 仅增加允许同源样式，认证和来源校验继续执行。

总览侧栏的资源、事件、数据连接、卡片库、设置均为当前页面内操作；从辅助页面打开这些入口时回到总览并展开对应内容。面板草稿、撤销/重做与 revision 冲突保护保留。

## 数据和兼容性

本次没有数据库迁移，不改资源 ID、面板 ID、Agent Token 加密、TOTP、SSO 注册或协议。资源编辑的空 Token 输入表示保留原凭据；清除必须显式勾选。服务器改为其他类型须确认清除连接；删除会提示受影响卡片数量。手动记录状态与 Agent 实时质量分开呈现。

备份入口移到“设置”。导出仍为原 JSON 格式；导入先显示资源和面板数量，再选择合并或替换并确认。替换会清除现有 SMA 凭据，JSON 不含 Token；面板有未保存布局时禁用恢复。完整恢复仍按运维手册操作。

已删除旧 `app/dashboard.tsx` 与 `app/workspace.css`。采用源码归档覆盖升级时必须同时移走这两个旧文件，放进受保护的源码备份目录；只覆盖新文件不会自动删除旧源码。不要清除数据卷或删除服务器的历史 `releases/` 目录。

## 验证边界

执行 `npm test`、`npm run lint`、`npm run build`；原生浏览器回归使用 `SMA_CENTER_BROWSER_TEST=1 npm test`，全部使用临时卷、测试认证和模拟 Agent。覆盖资源新增与加入面板、旧入口跳转、主题在 React/原生页面间同步、桌面及手机不溢出，并保留版本同步、TOTP 和 OIDC 回归。隔离模拟数据不等于真实数据库/中间件监控，也不等于物理手机或外部 SSO 客户端验收。实际上线结果另见[部署核对记录](deployment-status.md)。
