- [统一控制台方案与实现](unified-console.md)：以总览为核心的导航、资源管理、共用设计规范与升级注意事项。

- [部署核对记录](deployment-status.md)：当前环境和代码一致性核对结果；不是持续在线监控。

本项目当前是 **单用户、强制 TOTP 验证器登录的自托管服务**，可选择启用受限 OIDC SSO，为已注册业务系统提供统一身份；仍不支持账号密码或多租户登录。历史讨论中的功能方案不等于当前实现，以代码与本目录为准。
