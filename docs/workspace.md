# 面板与卡片

2026-11-06。本页说明已实现能力；设计讨论中的后续能力不能视为已交付。

## 使用

首页为统一面板，侧栏“资源”在总览中打开管理弹窗，旧 `/resources` 自动跳转。资源新增、编辑、收藏、Agent 连接和删除无需切换页面；设置中维护全站外观与 JSON 备份。其他页面共用导航，见[统一控制台方案与实现](unified-console.md)。原有资源、收藏、Agent 配置、服务发现、SSO、版本中心、安全设置及 JSON 备份入口保留。品牌图标采用本次选定的蓝色磁贴 S，包含登录页、主导航、favicon 与 Apple 触屏图标；PNG 为 AI 生成的品牌概念经尺寸转换，无 Apple 官方标识。

- 面板：侧栏 `+` 新建，最多 12 个。手机从右上菜单切换或新建。至少保留一个面板。
- 编辑：可修改名称，通过把手拖动排序，或用上下按钮移动；选择小、中、宽、整行尺寸。手机使用上下按钮，无需长按拖拽。
- 保存前所有改动为草稿；取消恢复服务器版本。撤销/重做保留最近 50 步。保存使用 revision 防止多标签页静默覆盖，冲突时保留草稿并提示，取消可重新读取最新版本。
- 添加卡片会进入编辑：资源、指标、趋势、收藏、文本、事件。标题可覆盖资源名，指标可选 CPU/内存/系统盘并设置显示阈值。此阈值只改变卡片提示，不修改后台告警规则。文本按纯文本呈现，不执行 HTML、脚本或命令。
- 资源卡可绑定工具、站点、服务器、数据库、中间件；数据库和中间件当前只展示元信息与入口，未接入性能指标。收藏卡列出资源管理中的收藏。
- 同一资源可以绑定多张卡片。移除卡片不删除资源，删除资源后卡片提示重新绑定。桌面 12 列，窄屏派生布局，手机单列；手机不会改写桌面尺寸。
- 卡片库不开放上传任意代码。当前 schema 无第三方运行时插件，新增卡片须通过受版本管理的注册表与配置校验。

UI 使用系统字体、稳定内容表面、蓝色操作强调及轻分隔线；保留原有明暗/密度偏好。不常驻显示「拖动」「个人空间」「仅自己可见」、欢迎口号或重复身份标签。无障碍名称保留操作含义，不作为视觉文案堆叠。

## 数据模型与迁移

新增 `dashboards`，保存所有者、名称、revision、版本化类型标识的声明式卡片配置与顺序。为每位用户首次访问原子创建默认「总览」，引用已有资源 ID；不会搬迁/复制/覆盖 Agent 凭据。资源元数据和卡片配置分开存储。

SQL 迁移仅增加面板、历史与事件表和索引，已有资源表仍兼容旧代码。资源类型扩展为 database/middleware，但既有侧栏排序偏好仍沿用原三类；新增类型从资源管理标签页访问。`db/schema.ts` 与 Drizzle SQL、快照及 journal 同步维护。

新增表本身不要求回滚时删除。旧 UI 不识别数据库/中间件类型：只要已有这类新资源，就不能把切换旧镜像视为可用回退，需要先提供兼容读取的新旧 UI，或另行授权恢复版本兼容的完整备份。完整恢复会丢失备份之后的数据；不要删除新表或恢复旧备份冒充无损回退。当前上线验收时资源仍为原三种类型，未新增测试资源。

页面 JSON 备份格式继续为 `sma-center-backup-v1`，增加可选 `dashboards`，并支持新资源类型；旧备份缺少 dashboards 时，合并保留原面板，替换后按需生成默认面板。旧应用不会备份新面板，不能用它做升级后的无损恢复。面板和卡片随 JSON 备份导入导出，监控历史、事件与凭据不含在 JSON 中，完整卷备份包含这些表及原密钥。合并面板会增加 revision，拒绝旧标签页写回覆盖。

## 持续采集、历史与事件

自托管生产 Next Node 进程通过 `instrumentation.ts` 注册采样器，启动约 5 秒后首轮，每 30 秒一轮，关闭浏览器仍采集。开发模式默认不启动；`SMA_CENTER_MONITOR_ENABLED=false` 可关闭，停止后历史仍保留，页面会显示关闭状态。该设置需重启生效，不修改认证或 Token。

当前路径专注 SMA 主机快照：按 ID 排序最多 100 个已配置 Agent 的服务器，最多 3 个并发任务，整轮未结束不重叠执行；每个上游请求沿用 5 秒快照/3 秒版本超时、响应大小限制和 30 秒缓存。相同用户/地址及凭据由采样器的 Monitor 缓存合并；页面快照接口有独立缓存，因此服务器详情仍可能增加一次上游请求。连接失败按 30 秒固定间隔重试；尚无指数退避或跨进程任务租约。

该版本只支持单个自托管实例/进程。不要横向扩容或在同一卷启动多个采样器。SQLite/WAL 作为首版小规模持久历史，SMA 每条样本只保存白名单百分比、版本、采样时间，不保存 Token、完整上游快照或命令行。周期清理超过 7 天的样本，已恢复事件保留 30 天；未恢复事件保持至恢复/资源删除。高资源规模或长期存储应后续迁移到独立时序后端，未进行生产规模压测。

指标差分、根盘匹配和平台不支持字段继续遵循 [SMA 指标口径](sma-metrics.md)。Agent 样本落后超过 90 秒或超前超过 30 秒拒绝为有效样本；最后一轮接收超过 90 秒显示数据过期。首次 CPU/I/O 不显示零；采集失败或页面数据更新失败不显示为健康，部分失败只保留有效指标。

趋势查询支持 1/6/24 小时和 7 天，限定拥有的资源和三个指标，最多 361 个平均桶；异常或缺失样本所在桶显示断点，不连成假趋势。仅在查询时降采样，不预填历史。尚无采样时显示空状态。

内置事件：SMA 连接连续失败 3 次；CPU/内存/系统盘 >=90% 持续 5 分钟。低于 85% 恢复高占用事件，连接成功恢复连接事件；缺失或异常样本不会恢复指标事件。采样间隔超过 90 秒或连接配置改变时会重新计时。重启会清空短期计数与高占用计时，重新等待阈值持续时间，已产生事件持久保留。事件按资源/类别去重，支持确认、静默 1 小时、取消静默与恢复状态。目前无邮件/Webhook/推送通知，静默只隐藏面板待处理项，不丢弃历史事件。

## 后续范围

尚未实现：数据库/exporter 性能连接器、主动 HTTP/TLS 站点探测、日志与链路、依赖拓扑、团队共享、用户自定义后台告警规则、外部时序查询服务、多进程调度。资源发现只能作为资产识别，不能冒充数据库性能监控。后续按连接器 → 历史/规则 → 跨信号关联逐项接入，继续复用面板卡片协议。

## 验证

自动回归包含配置校验、卡片移动、默认资源投影、SQL 迁移、并发冲突，以及可选真实浏览器/隔离网关/模拟 Agent 验证。执行 `npm test`、`npm run lint`、`npm run build`。真实浏览器入口为 `SMA_CENTER_BROWSER_TEST=1 npm test`，会新建临时数据与认证状态，不读取或修改生产卷。

部署版本、实际运行检查与未验收项记录在 [部署核对记录](deployment-status.md)；本地构建通过不等于生产已更新。
